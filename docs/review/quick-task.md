# L2 快速评审任务

评审当前分支相对 `main` 的 diff（`git diff main...HEAD`），以及变更文件的**直接关联上下文**（调用方 / 被引用方 / 相关类型定义）。不要评审未变更的无关文件。

## 只报告 blocking 级别问题

- 构建 / 编译错误
- 运行时崩溃（空引用、错误的 Hook 用法等）
- 明显逻辑错误（条件反转、状态更新丢失、错误的 API 路径等）
- 安全问题（密钥硬编码、XSS 注入、敏感信息泄露等）

不报告风格、命名、可优化项等 non-blocking 问题。

## 输出格式

总长度不超过 20 行。逐条给出：

```
- [blocking] <文件>:<行号> — <问题描述> — <修复建议>
```

如果没有 blocking 问题，只输出一行：`NO_BLOCKING`。
